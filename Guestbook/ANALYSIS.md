## 의도적으로 사용하지 않은 요소

- React, Vue, JavaScript: 서버 렌더링 HTML 폼만으로 요구사항을 충족합니다.
- Jinja2, python-multipart: 새 라이브러리를 늘리지 않기 위해 표준 라이브러리로 HTML과 폼을 처리합니다.
- ORM: 테이블이 하나뿐이므로 내장 `sqlite3`와 매개변수 SQL이 더 단순합니다.
- 외부 API와 비동기 HTTP 호출: 방명록 핵심 기능에 필요하지 않습니다.
- 테이블 관계: `entries` 테이블 하나만 사용합니다.

## 데이터 흐름

1. 사용자가 `/`에서 이름과 메시지를 작성합니다.
2. 브라우저가 `POST /entries`로 폼을 보냅니다.
3. `GuestbookCreate`가 길이와 공백을 검증합니다.
4. 검증된 값만 매개변수 SQL로 SQLite에 저장합니다.
5. 서버가 `303`으로 `/`에 돌려보내고 최신 글부터 HTML로 표시합니다.

화면에 출력할 때는 `html.escape`를 사용해 입력 문자열이 HTML 코드로 실행되지 않도록 처리합니다.
